# Models Directory (Output)

Lưu trữ các file trọng số (`.weights.h5`) hoặc checkpoint của mô hình sau khi huấn luyện.

## Lưu ý

- Nội dung của folder này được bỏ qua bởi `.gitignore`.
- Mỗi model được lưu với tên dạng: `<model_name>_<timestamp>.weights.h5`.
- File checkpoint tạm thời sẽ được lưu ở đây trước khi được đánh giá cuối cùng.
