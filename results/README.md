# Results Directory

Lưu trữ kết quả huấn luyện & đánh giá của các mô hình.

## Subfolders

- `results/metrics/` — File `.json`/`.csv` chứa các số liệu (accuracy, precision, recall, F1, ...) ở dạng bảng.
- `results/plots/` — Hình ảnh: loss/accuracy curve, confusion matrix, ROC curve.
- `results/reports/` — Báo cáo tổng hợp dạng `.md` hoặc `.html`.

## Lưu ý

- Nội dung thực tế được bỏ qua bởi `.gitignore`.
